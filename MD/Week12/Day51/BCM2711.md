## ARM physical address
* physical addresses start at 0x0_0000_0000 for RAM
* The ARM section of the RAM starts at 0x0_0000_0000 and extends up to the size fo installed SDRAM
* VideoCore section -> 0x0_4000_0000 downwards
	* The bus addresses for RAM are set up to map onto uncached bus address ragne on the VideoCore starting at 0x0_0000_0000
* Physical address range from 0x4_7C00_0000 to 0x4_7FFF_FFFF for main peripherals
	* available from 0x0_FC00_0000 to 0x0_FF7F_FFFF 
	* Local peripherals available from 0x0_FF80_0000 to 0x0_FFFF_FFFF

## Legacy Master Address
* SW accessing peripherals using the DMA engines must use 32-bit legacy master addresses
* The Main peripherals are available from 0x7C00_0000 to 0x7FFF_FFFF
* A peripheral described in this document as being at legacy address 0x7Enn_nnnn is available in the 35-bit address space at 0x4_7Enn_nnnn
* And visible to the ARM at 0x0_FEnn_nnnn if Low Peripheral mode is enable
* SW accessing RAM using the DMA engines must use legacy addresses (between 0xC000_0000 and 0xFFFF_FFFF)
* This accesses a 1GB window within the full 16GB SDRAM address space
* If the DMA engine needs to access RAM above the first 1GB, this window can be moced using the PAGE or PAGELITE bits
