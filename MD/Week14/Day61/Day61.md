#### 학습 내용 추후 인공지능 툴을 이용해 수정 진행
- 화소 처리
	- convertTo
- 이진화
	- threshold 사용
	- LookupTable
- 감마 보정
	- 입력 화소 값 비선형 변환으로 영상 밝기 보정
* 영상 합성 => 선형영상합성
	* 논리적은 영상 합성
* 히스토그램 사용
	* 특정한 값을 화소가 영상 안에 몇 개나 있는지 막대 그래프로 표시
* 평균값 필터링
* 가우시안 필터링
* 샤프닝
	* 영상 날카롭게
	* 주변 픽셀과의 차이 극대화, 경계 부분 명암 비 증가
	* 영상 선명할게 할 때 사용
* 공간 필터링
	* 평균 필터, 가우시안 필터, 샤프닝 필터
* 에지 검출
	* 화소 밝기가 급격하게 변하는 부분 -> 에지
	* 에지 검출 가능하면 물체의 윤곽선 확이 ㄴ가능
	* 1차 미분/2차 미분값 사용 방법, 그 외
	* 소벨 엣지 검출 알고리즘
		* 1차 미분 방식, 기본적이고 빠르며 노이즈 억제를 위한 스무딩 효과 존재
		* 정밀도가 낮고 약한 엣지를 잘 잡지 못함
	* 캐니 엣지 검출 알고리즘
		* 가장 복잡, 가장 정교한 엣지 검출
		* 얇고 연속적인 엣지, 노이즈에 강함
		* 파라미터 설정 중요, 비교적 느림
	* scharr 방식
		* sobel보다 개선된 커널 사용
	* 라플라시안
		* 2차 미분 방식
		* 빠르게 전체 엣지 추출 가능
		* 노이즈에 민감, 블러 전처리 필수
	- 중간값 필터링
		- medianblur
	- 기하학 변환
	- 보간법
