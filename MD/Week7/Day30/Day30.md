## 프로세스 관리
#### 1. 컴퓨터의 작동 원리와 프로세스
1. 컴퓨터의 작동 원리
	* CPU : 프로그램의 명령어를 해석해 산술 연산, 논리 연산 등 모든 연산을 수행하는 컴퓨터의 두뇌
	* 레지스터 : CPU 내부에 포함된 아주 작고 빠른 메모리
		* 프로그램 카운터, 링크 레지스터 등 다수 존재
	* RAM : 프로그램 코드와 데이터를 저장하는 공간으로 휘발성 메모리
	* 저장 장치 : 하드 디스크 드라이브, SSD, 플래시 메모리와 같은 저장소로 비휘발성 메모리
	* 시스템 버스 : 컴퓨터 내부에서 데이터를 주고 받는 통로
2. 프로세스란?
	* 프로세스 : 메모리에서 실행 중인 프로그램
		* 부모 프로세스 : 프로세스를 생성한 프로세스
		* 자식 프로세스 : 부모 프로세스가 생성한 프로세스
			* 하나의 스레드로 구성 -> 프로세스가 타 프로세스를 생성 가능
	* 프로그램 : 디스크에 저장된 실행 파일

3. init 프로세스
	* init 프로세스 : 리눅스 커널이 부팅하면서 만들어내는 최초 프로세스, PID 1부여
	* system : init 프로세스와 같은 역할 초기화 프로세스, init보다 성능 좋고, 로그 및 자원 관리 측면에서 강력하고 유연한 기능 제공
	* 프로세스 종료
		1. 자식 프로세스가 종료될 때까지 무한히 대기
		2. 부모 프로세스가 다른 작업을 하다가 주기적으로 자식 프로세스가 종료됐는지 확인(Polling)
		3. SIGCHLD 시그널 수신 시 자식 프로세스 종료 처리
	* 좀비 프로세스 : 프로세스가 종료됐지만 종료 처리를 하지 않아 프로세스가 완전히 정리되지 않은 상태
	* 고아 프로세스 : 부모 프로세스가 자식 프로세스보다 먼저 종료된 경우

#### 프로세스의 작동
* 프로세스의 생애 주기
	* 프로세스가 생성, 실행, 종료(소멸)되는 과정
* 멀티 태스킹을 위한 여러 기법
	* 여러 일을 동시에 처리하는 것
	* 프로세스 스케줄링
		* 여러 프로세스 중에 CPU가 처리할 프로세스를 결정하는 행위
		* 스케쥴러 : 스케줄링을 담당하는 주체
	* 스케줄링 알고리즘
		* 프로세스 스케줄러가 처리할 프로세스를 선택하는 방법
	* 스케줄링 알고리즘이 가져야 할 속성
		* 공평성 : 모든 프로세스가 공평하게 처리
		* 우선 순위 : 설정된 우선순위에 따라 스케줄링이 가능해야 함
		* 효율성 : 시스템 자원을 효율적으로 사용할 수 있는 방법 제공
		* 응답 시간 : 사용자나 프로세스가 요청한 동작에 대한 응답 시간을 최소화
* 컨텍스트 스위칭
	* 프로세스 스케줄링에 따라 처리되는 프로세스가 변경되는 일련의 과정
	* 프로세스 제어 블록(PCB, Process Control Block) : 프로그램 카운터 레지스터, 스택 포인터 레지스터 등 레지스터 값과, 프로세스 상태 정보, 메모리 상태 정보 등을 저장
![[Pasted image 20260506104017.png]]
* 프로세스 상태
	* 실행/실행 대기 상태(running / runnable) : 프로세스가 CPU에 의해 처리 중(실행)이거나 처리되기를 기다리는(실행 대기) 상태
	* 중단 상태(stopped) : 프로세스 중단 시그널(SIGSTOP)을 받아 프로세스가 멈춘 상태
	* 종료 상태(terminated) : 프로세스가 exit() 함수 등에 의해 종료된 상태
		* 프로세스 종료 상태(process exit status) : 프로세스가 어떻게 종료 됐는지 확인하는 상태 코드
		* 0 : 정상 종료, 1 : 문제
	* 수면 상태(sleep) : 프로세스가 오랜 기간 어떤 이벤트를 기다리는 상태, 인터럽트에 의해 깨어날 수 있는 수면 상태와 깨어나지 않는 수면 상태가 있음
		* interruptible, uninterruptible sleep
![[Pasted image 20260506104738.png]]

* 스레드
	* 프로세스의 가장 작은 실행 단위
	* 싱글 스레드 프로세스 : 프로세스 내에 스레드가 1개만 존재
	* 멀티 스레드 프로세스 : 프로세스 내에 스레드가 여러 개 존재

#### 파일 디스크립터와 표준 스트림
* 파일 디스크립터
	* 파일 등을 관리하는 추상화된 개념
* 표준 입력 스트림
	* 프로세스가 키보드 등 입력 장치로부터 데이터를 입력받는 스트림
	* 데이터 입력만 가능
	* 파일 디스크립터 번호가 항상 0
* 표준 출력 스트림
	* 일반적인 내용을 출력할 때 사용하는 스트림
	* 데이터 출력만 가능
	* 파일 디스크립터 번호가 항상 1
* 표준 에러 스트림
	* 에러 메시지 출력할 때 사용하는 스트림
	* 데이터 출력만 가능
	* 파일 디스크립터 번호가 항상 2

#### IPC
* 파이프
	* IPC(Inter-Process Communication) : 프로세스 간 통신에 사용하는 도구
	* 두 프로세스 간 데이터를 전송할 때 쓰는 IPC
	* 명명된 파이프 : 파일 형식의 이름을 부여할 수 있는 파이프
* 메시지 큐
	* 정해진 큐에 메시지를 넣고 빼는 방식으로 데이터를 교환하는 자료구조
	* 먼저 들어간 데이터가 먼저 나오는 선입선출 방식
* 소켓
	* 네트워크로 연결된 다른 시스템에서 작동하는 프로세스와 통신할 때 사용
	* 인터넷 소켓 : 네트워크 통신을 위한 소켓
	* 유닉스 도메인 소캣 : 소켓의 성질을 그대로 이용하면서 시스템 내부 통신에도 이용
* 공유 메모리
	* 데이터 장체를 공유
	* 프로세스 <-읽기/쓰기-> 공유 메모리 <-읽기/쓰기-> 프로세스
* 세마포어
	* 임계 영역을 보호하기 위한 수단, 공유 메모리에서 프로세스의 동시 접근을 제한하거나 프로세스의 순서를 조절할 때 사용
* 카운팅 세마포어
	* 어떤 자원을 n개 프로세스만 사용할 수 있게 할 때 사용
* 바이너리 세마포어 / 뮤텍스
	* 자원을 독점적으로 사용할 수 있도록 세마포어의 초기 설정 값을 1로 설정하는 세마포어

## Bash : 조건문과 테스트 연산자
#### 변수에 값 저장
* 변수 : 데이터를 담는 그릇
* 할당 : 변수에 값을 저장하는 것
* 쿼팅 : 값을 따옴표로 감싸는 것
	* $ value_name = value
* 변수 사용 
	* 변수 이름을 중괄호로 묶고 가장 앞에 $ 붙임
	* 중괄호 생략 후 변수 명 앞에 $만 붙여도 됨
* 변수의 데이터 타입
	* 데이터 타입 : 변수에 저장하는 값의 유형
	* Bash에서 변수의 데이터 타입 : 모든 데이터를 문자열로 처리
* 변수로 산술 연산 방법
	* let : 표현식 부분에 변수를 포함한 산술 연산식을 넣으면 변수로 산술연산 가능
		* $let "표현식"
	* expr : 따옴표 사용하지 않고 사용 가능
		* $expr 표현식
* 조건문
	* if - then - fi
	* if - then - else - fi
	* ```zsh
	  if 조건1; then
	  명령
	  fi
	  ```
	* 조건
		* 참 : 조건 부분 명령 실행해 프로세스 종료 코드로 0을 받을 때
		* 거짓 : 0이 아닌 값을 받을 때
	* 싱글 브래킷 : Bash의 조건문에 사용하는 \[명령어]
	* 더블 브래킷 : 싱글 브래킷 단점 보완, POSIX 표준이 아니라 호환성이 중요한 경우 사용 안함 \[\[명령어]]
* ```bash
  case exp in
  {
  }
  ```

 * return 및 선언부 없음
 * 매개변수가 있는 함수
	 * 인자 : 함수 입력
	 * 매개변수 : 함수 실행될 때 함수 내에서 인자의 값을 저장
	 * 반환값 : 함수의 출력
* 특수 매개변수
	* 위치 매개변수 : 함수의 매개변수를 순서대롤 $1, $2, $3 등으로 사용할 수 있어 붙은 이름
	* $# : 스크립트나 함수의 매개변수 개수를 나타내는 특수 매개변수
	* $0 : 실행 중인 스크립트 파일의 이름을 나타내는 특수 매개변수
	* $* : 스크립트나 함수의 모든 위치 매개변수를 하나의 문자열로 인식하는 특수 매개변수
	* $@ : 스크립트나 함수의 위치 매개변수를 각각 인식하는 특수 매개변수
	* $? : 최근에 실행된 명령이나 함수, 스크립트의 프로세스 종료 코드 또는 반환 값을 나타내는 특수 매개변수
	* \$$ : 실행중인 셸의 PID를 반환하는 특수 매개변수
* 변수의 export
	* 셸에서 선언한 변수를 새로운 스크립트에서도 사용할 수 있게 함
* 환경변수
	* 운영체제에서 사용자 환경에 대한 정보를 담고 있는 변수
#### 배열
* 인덱스 배열 : 일반적으로 배열이라 하면 흔히 떠올리는 형태
* 연관 배열 : 키와 값의 쌍으로 이뤄진 자료구조
	* $declare -A val
	* 할당 : $ val\[key] = val
	* 요소 하나 값 참조 : $ {val\[key]}
	* 모든 요소 값 참조 : ${변수\$\[@]}
